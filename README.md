# 班级同学状态与需求了解表

面向班级心理委员的**匿名问卷应用**：同学们点开链接即可匿名填写，数据进入云端数据库；心理委员用密码登录结果页查看统计、导出 CSV，用于班会排期与日常关怀。

**零后端代码**——数据能力由云数据库提供，本仓库只有 3 个静态文件。

## 功能

- **匿名填表**：14 道题（5 大板块），约 3 分钟填完，无需登录、不采集任何身份信息
- **手机优先**：响应式布局，班群转发后同学用手机直接打开
- **密码门禁统计**：结果页需密码才能查看，密码校验在服务端完成，前端源码里看不到
- **实时统计**：回收份数、适应度均分、愿意单独聊的人数、各题选项分布条形图、匿名留言列表
- **CSV 导出**：一键导出全部原始回答
- **危机出口**：结尾固定展示心理热线；问卷不做筛查判定，危机信号走观察与转介

## 目录结构

```
.
├── README.md          ← 本文件
├── LICENSE            ← MIT 许可证
├── .gitignore
└── docs/              ← GitHub Pages 站点目录（Settings → Pages → Source 选 /docs）
    ├── index.html     ← 填表页（站点首页，发给同学的就是它）
    ├── results.html   ← 结果统计页（仅心理委员使用，需密码）
    └── cloud-mini.js  ← 轻量云数据库客户端（约 50 行，替代官方 SDK）
```

> 仓库内**不含任何密钥**：数据库连接配置由页面打开时从线上实时拉取。

## 本地预览

```bash
cd docs && python -m http.server 8000
# 填表页  http://localhost:8000/index.html
# 结果页  http://localhost:8000/results.html
```

## 部署

### 方式一：GitHub Pages（推荐，链接形如 https://<用户名>.github.io）

1. 把本目录推送到名为 `<用户名>.github.io` 的公开仓库
2. 仓库 **Settings → Pages → Source** 选 **`main` 分支的 `/docs` 目录**，保存
3. 约 1 分钟后访问：
   - 填表页 `https://<用户名>.github.io`
   - 结果页 `https://<用户名>.github.io/results.html`

### 方式二：Cloudflare Pages

1. 登录 <https://dash.cloudflare.com> → **Workers 和 Pages → 创建 → Pages → 上传资产**
2. 项目名起英文小写名，上传 `docs/` 里的 **3 个文件**
3. 部署完成即得 `https://<项目名>.pages.dev`（填表页在首页，结果页在 `/results.html`）

### 方式三：其他静态托管

Netlify、Vercel、Gitee Pages、阿里云 OSS 等均可，把 `docs/` 下 3 个文件传上去即可，无构建步骤。

## 数据说明

| 项目 | 说明 |
| --- | --- |
| 数据存哪 | 云数据库（PostgreSQL），匿名 INSERT-only 策略：任何人可写入、无人可读取 |
| 谁能看结果 | 仅结果页密码门禁（服务端校验），密码不在前端源码中 |
| 改班级名 | 联系部署方修改线上配置，两个页面标题同步生效 |
| 改查看密码 | 联系部署方修改服务端校验函数 |
| 导出 | 结果页右上角「导出 CSV」 |

## 使用流程

1. **发放**：把填表页链接发班群（建议附一句自愿说明）
2. **跟踪**：随时打开结果页看回收进度与「愿意单独聊」人数
3. **行动**：按结果安排班会主题与个别关心；留了联系方式的同学主动一对一沟通
4. **归档**：回收结束后导出 CSV 存档

## 红线（心理委员场景）

- 回收结果只用于班会排期与日常关怀，**不下任何诊断性结论**
- 发现危机信号（自伤/伤人表述等）走观察与转介流程，不走问卷
- 热线号码以学校官方最新发布为准
- 填写完全自愿，不向任何人公开个人答案
